# الأمير تيك — ALAMEER TECH

واجهة متجر إلكترونيات عربية فاخرة باستخدام HTML وCSS وJavaScript.

## التشغيل
افتح `index.html` في متصفح حديث. لا توجد حزم أو خطوات بناء مطلوبة.

## الميزات
- كتالوج منتجات وفلاتر حسب التصنيف والبحث.
- تفاصيل المنتج في نافذة منبثقة.
- عربة تسوق، كميات، وحساب إجمالي مع حفظ محلي.
- نموذج تسجيل دخول تجريبي (LocalStorage فقط).
- نموذج إتمام طلب تجريبي.
- لوحة لإضافة وحذف المنتجات محليًا.
- تصميم RTL متجاوب.

## نشر GitHub Pages
1. أنشئ مستودعًا عامًا جديدًا على GitHub.
2. ارفع `index.html`, `style.css`, `script.js`, و`README.md`.
3. افتح Settings → Pages.
4. اختر Deploy from a branch، الفرع `main` والمجلد `/ (root)`.
5. احفظ وانتظر رابط النشر.

## تنبيه مهم
هذه نسخة Frontend تجريبية. الحسابات، الطلبات، المنتجات والسلة تُحفظ في متصفح المستخدم فقط. لا يوجد backend أو تحقق آمن من الحسابات أو إدارة مخزون مركزية أو بوابة دفع. لا تستخدمها لمعالجة بيانات حقيقية أو مدفوعات قبل ربط backend موثوق وخدمة دفع.
